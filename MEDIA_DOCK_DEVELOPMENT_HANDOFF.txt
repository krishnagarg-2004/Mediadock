MEDIA DOCK — DEVELOPMENT HANDOFF
--------------------------------------------------

1. PROJECT IDENTITY

- Project Name: MediaDock
- Target Platform: Windows 10 / 11 (PySide6 / Win32 / WinRT)
- Application Purpose: Ambient desktop media playback control overlay & system tray utility.
- Core Product Concept: Top-center anchored Dynamic Island-style media control widget.
- Architectural Integrations:
  - GSMTC (Global System Media Transport Controls): Intercepts system media sessions (Spotify, YouTube, VLC, etc.) via WinRT API.
  - MediaCore: Engine coordinator bridging raw media sessions, playback controls, volume state, and UI event signals.
  - Windows Volume Control: Integrates system audio endpoint control via CoreAudio Win32 COM / Pycaw.
  - System Tray: Background process host with context menu for Show/Hide, Settings, and Exit.
  - Global Hotkeys: OS-level keyboard shortcuts registered via Win32 `RegisterHotKey`.
  - Dynamic Island UI: Frameless top-center floating window morphing cleanly between HIDDEN, COLLAPSED capsule (`180x40`), and EXPANDED card (`360x160`).

--------------------------------------------------
2. PROJECT ARCHITECTURE

- `src/main.py`: Main application entry point, `QApplication` initialization, single-instance guard check, coordinator wiring, and tray/window setup.
- `src/core/media_core.py`: Application coordinator managing active media session providers, playback state, track metadata, and volume state signals.
- `src/core/settings.py`: Persistence manager (`SettingsManager`) over `QSettings` INI storage with default clamping and key-value safety.
- `src/core/single_instance.py` / `src/ui/hotkeys.py`: Win32 single-instance IPC server & global hotkey manager using native Windows event filters (`WM_HOTKEY`).
- `src/ui/main_window.py`: Core frameless window hosting the Dynamic Island layout container, state transitions, hover enter/leave events, and collapse timer.
- `src/ui/components_island.py`: Presentation widgets including `CollapsedCapsuleWidget` (`180x40`), `ElidedLabel`, `ReactiveVisualizerWidget`, and source icon mapping.
- `src/ui/frameless_window.py`: Custom base frameless window with pure black background/border path painting.
- `src/ui/settings_dialog.py`: Preferences dialog hosting configuration controls, spinboxes, and `ShortcutRecorderWidget`.
- `src/ui/system_tray.py`: System tray icon (`SystemTrayIcon`) and context menu integration.
- `src/ui/theme.py`: Centralized color tokens (`COLOR_BG_ISLAND`, `COLOR_BORDER_ISLAND`), button stylesheets, and `get_svg_pixmap`/`get_svg_icon` vector engine.
- `assets/icons/`: Standardized SVG vector assets (`play.svg`, `pause.svg`, `previous.svg`, `next.svg`, `volume.svg`, `mute.svg`, `spotify.svg`, `youtube.svg`, `vlc.svg`, `default_media.svg`).
- `tests/`: 201 automated unit & integration test files covering core models, settings, hotkeys, state machine, top-center positioning, capsule layout, SVG icons, and shortcut recorder.

7. GLOBAL SHORTCUT RECORDER

- Component: `ShortcutRecorderWidget` in `src/ui/settings_dialog.py`.
- Functionality: Replaces legacy text fields with interactive key-capture controls.
- Interactive Flow:
  User clicks Record -> Enters recording mode -> Listens to native `keyPressEvent` -> Captures modifier + key combination -> Validates length -> Renders key pill badges.
- Strict Key Rules:
  - Exactly 2 keys (1 modifier + 1 key) allowed (e.g. `Ctrl+M`).
  - Exactly 3 keys (2 modifiers + 1 key) allowed (e.g. `Ctrl+Alt+Space`).
  - 1-key shortcuts REJECTED with message `"Shortcuts must contain at least 2 keys (e.g. Ctrl+M or Ctrl+Alt+M)."`
  - 4+ key shortcuts REJECTED with message `"Shortcuts cannot exceed 3 keys."`
- Conflict & Windows Registration Error Reporting:
  - Detects duplicate assignment between Show/Hide and Play/Pause: `"Show/Hide and Play/Pause cannot use the same shortcut."`
  - Reports Windows OS registration failure cleanly on `lbl_error`.
  - Automatic rollback in `GlobalHotkeyManager` if registration fails.
- Manual Verification Status: Source implementation complete and 100% test-backed; packaged binary manual verification pending.
